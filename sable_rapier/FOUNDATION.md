# Planetary foundation native extension

Upstream Sable base: `6966d2928340de7631abcecf8549904b877df0a8` (Minecraft 1.21.1, 2.0.5). Existing compact-body Java/JNI methods and f32 Rapier backend are unchanged.

`rapier/src/foundation.rs` adds ABI 1, a bounded f64 native scene backend for streamed cubic terrain. It uses real Rapier rigid bodies, compound voxel collision, contacts, CCD, fixed constraints, sleeping and queries. Terrain is an exact greedy cuboid partition of occupied 16³ cells. Legacy material calls remain binary full-cube/air. Streaming capability 2 also accepts prepared cube-local AABB compounds, preserving slab/stair geometry supplied by the add-on. Minecraft block-state evaluation remains outside native code. A native scene is independent of any Minecraft plot or celestial mass.

Both precisions use Ryan's Rapier source `38e92f117590862481a53df6fc69a5d893e29186` and Parry 0.26.0. The f64 backend has four focused internal origin-shift methods and an optional per-body gravitational acceleration field. The latter overrides scene gravity without modifying user force accumulators and is evaluated once during each native substep. Clearing it restores ordinary scene gravity. `scripts/Prepare-FoundationRapier.ps1` exports the pinned source into an ignored directory and applies `patches/rapier-region-origin.patch`. It retains upstream Apache-2.0 licensing, source revision and patch/file hashes. The original f32 dependency still comes directly from the pinned git revision without this patch.

Translation changes every native body current/queued pose and world COM, collider world pose, cached solver contact point and padded BVH leaf. It preserves local constraint anchors, collider-relative offsets, velocities, sleep flags, modification queues and warm starts. Solver scratch buffers are discarded. Region handles are registry keys, not externally supplied pointers. Calls serialize through a registry mutex and Java owner-thread confinement; concurrent simulation throughput and automatic merging are not claimed.

Prepare generated Rapier before Cargo:

```powershell
./sable_rapier/scripts/Prepare-FoundationRapier.ps1
```

The Planetary Sable repository's `scripts/Build-FoundationNative.ps1` builds the Windows DLL and writes native identity. Its `scripts/Test-FoundationNative.ps1` owns headless fixtures. No upstream installation is changed by these commands. A package replaces the Windows entry inside the existing Sable nested native library; it does not load a second Sable provider.

Caps: 64 live scenes; 4,096 live streamed section leases, 4,096 bodies and 4,096 joints per scene; +/-512m local coordinates. Legacy terrain retains its historical revision tombstones. Streamed terrain uses increasing leases and a high-water mark to retire metadata permanently without permitting stale resurrection. Legacy and streamed lifetime APIs cannot mix in one scene. Geometry has at most 8,192 primitives per cube and 131,072 primitives globally, counting both resident and prepared shapes. Up to eight preparation slots include work currently constructing geometry and completed unpublished shapes. Preparation validates and constructs compounds outside the simulation registry lock, then publication validates the lease and attaches the prepared shape. Unused preparations must be disposed. Replacement requires budget for old and new geometry concurrently; admission fails explicitly when that headroom is unavailable. Native body removal releases its colliders and attached joints. Cross-scene transfer remains unimplemented. The outer world service owns global residency admission. Native scene metadata is never a planet mass source. Dynamic boxes enable a two-meter speculative-contact prediction window; the unchanged hard-CCD switch alone did not satisfy the fixture penetration bound. This is a local-physics quality setting, not a claim that arbitrary flight speeds are qualified.

Typed transfer capability 1 is under qualification. It stages complete source/destination native simulation records, retains persistent integer body/joint IDs separately from handles, validates collision mappings and swept explicit-air readiness, and remaps contact manifolds/workspaces and joint impulses before atomic commit. One staging transaction is allowed. Authoritative plus staged copies are checked against 16384 body instances, 32768 colliders, 16384 joints, 32768 contact pairs, 65536 manifolds and 262144 contact/solver points. Shared immutable compound shapes retain their existing primitive allocation reservation. Cross-scene matched-control acceptance is pending; compile success alone does not establish continuity.
